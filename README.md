# ДЗ по разделу 5: сдвиги и растяжения

Откройте `index.html`. Это самостоятельный статический сайт: для публикации выложите **содержимое папки dz5** в корень отдельного сайта (или репозитория с GitHub Pages). Сборка и сервер не нужны. Шрифты грузятся из Google Fonts, без интернета сайт тоже работает, только со стандартными шрифтами.

## Что внутри

| Раздел | Что делает ученик |
|---|---|
| Шпаргалка | шесть преобразований: f(x + b), f(x) + c, a·f(x), f(kx), f(\|x\|), \|f(x)\|, с правилом для точек; анимации на x, x², x³, √x, 1/x; галерея «каждая базовая функция в каждом преобразовании»; порядок шагов для сложной формулы; ловушки |
| ДЗ 1. График ↔ формула | 11 задач: определить преобразование по графику, записать формулу, выбрать график по формуле |
| ДЗ 2. Точки, вершины, ловушки | 10 задач: куда переходит точка при f(x − 1) + 4, 2f(x), f(2x); вершина; что не двигает вершину; найти ошибку; асимптоты; число решений \|x² − 4\| = 3 |
| Рисуем по шагам | 10 формул, разбитых на шаги. На каждом шаге ученик выбирает, что происходит с графиком, ставит точки на клетках и соединяет их карандашом |
| Босс-задания | 8 формул без подсказок: ученик сам выбирает базовую функцию, собирает план шагов (порядок важен) и строит итоговый график |
| Тренажёр «Формула по графику» | бесконечные графики трёх уровней: только сдвиги → растяжения и отражения → модули. Неверная формула рисуется синим поверх |
| Тренажёр «Куда уедет точка» | бесконечные задачи: точка A на y = f(x), куда она попадёт после преобразования |

## Как работает рисование

1. **Точки.** Клик ставит точку на пересечении клеток (шаг 0,5), повторный клик убирает. Проверка требует: все точки на графике, есть ключевые (вершина / начало / центр, точки на оси x после |f(x)|, точка сгиба на оси y после f(|x|)), не меньше 5 точек (у корня — 3), у гиперболы и у f(\|x\|) — хотя бы по две точки с каждой стороны.
2. **Карандаш.** Открывается после верных точек. Линия засчитывается, если 85% её длины лежит не дальше 0,33 клетки от графика и она проходит через все отмеченные точки. Места, где линия ушла, подсвечиваются красным.
3. После двух неудачных проверок появляется «Показать ответ». Такой шаг отмечается в отчёте как подсмотренный.

## Отчёт для учителя

На главной кнопка «Отчёт для учителя» копирует сводку: сколько решено в каждом разделе, где подсмотрено решение, сколько графиков и точек в тренажёрах. Прогресс хранится в `localStorage` браузера ученика (ключ `funkcii9-dz5`, отдельно от основного сайта и от других домашек), на сервер ничего не уходит.

## Код

```
js/parser.js, plot.js, ui.js   копия движка основного сайта
js/app.js                      страницы, прогресс, отчёт (как в dz/)
js/tf.js                       базовые функции, шесть преобразований, перенос точек, доска для рисования
js/pages/theory.js             шпаргалка
js/pages/hw.js                 ДЗ 1 и ДЗ 2
js/pages/draw.js               рисуем по шагам
js/pages/boss.js               босс-задания
js/pages/trainers.js           два бесконечных тренажёра
```

Новое упражнение «по шагам» — объект в `EXS` (`js/pages/draw.js`): базовая функция, окно и шаги `[{ t, v }, "формула шага"]`. Типы шагов: `in` — f(x + v), `out` — f(x) + v, `a` — v·f(x), `k` — f(v·x), `abs` — |f(x)|, `absx` — f(|x|). Точки и ключевые точки посчитаются сами. Новый босс — объект в `BOSS` (`js/pages/boss.js`): формула, окно, подсказка.
